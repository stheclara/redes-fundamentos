# Fundamentos de Redes de Computadores

Repositório criado para registrar meus estudos e práticas sobre redes de computadores, com foco no aprendizado de conceitos fundamentais e ferramentas utilizadas na área de infraestrutura.

## Conteúdos estudados

- Configuração básica de rede
- Endereço IPv4
- Máscara de sub-rede
- Gateway padrão
- Testes de conectividade com `ping`
- Resolução de nomes com DNS
- Consulta de DNS com `nslookup`
- Rastreamento de rota com `tracert`

## Laboratórios

### 01 - Diagnóstico básico de rede

Primeiro laboratório prático realizado no Windows utilizando os comandos:

- `ipconfig`
- `ping`
- `nslookup`
- `tracert`

Durante a prática, utilizei esses comandos para consultar a configuração da rede, testar a conectividade, observar a resolução de nomes e analisar o caminho percorrido até um destino.
